================================================================================
HOW TRAINING WILL USE THIS DATA
================================================================================

The JEPA model will learn to:

1. ENCODE geometry (point cloud) into latent features
   Input: 2048 × 3 point coordinates

2. CONDITION on physics parameters (graph metadata)
   Input: 49-dim vector encoding:
   • 16-dim: Family one-hot (nose_cone, nozzle, tank, fin, combustion_chamber, etc.)
   • 16-dim: Physics regime (Mach, Reynolds, temperature, pressure ranges)
   • 8-dim: Geometry features (material, cooling method, size ratios)
   • 9-dim: Legacy/other features

3. PREDICT physics fields given context
   Output: 2048 × 6 field features
   • Pressure (Pa)
   • Velocity magnitude (m/s)
   • Stress (Pa)
   • Heat flux (W/m²)
   • Others (custom fields)

4. LEARN the relationship between:
   • Geometry shape → Physics behavior
   • Operating parameters → Field distributions
   • Component design → Performance metrics

The model learns directly from the graph structure, enabling:
  ✓ Generalization across different component types
  ✓ Transfer learning from related geometries
  ✓ Physics-aware CAD optimization
  ✓ Solver-free inference for rapid design iteration
